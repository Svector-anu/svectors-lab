*daily — 2026-09-12*

_TL;DR: EU vulnerability reporting is now on a 24-hour clock while agent platforms move from demos to durable execution._

1. *EU cyber reporting deadlines are now live*
   Manufacturers selling digital products in the EU must report actively exploited vulnerabilities or severe incidents through the CRA platform: early warning within 24 hours, full notice within 72 hours. Open-source stewards enter scope in December 2027.
   Why it matters: affected teams need an incident-to-regulator path now, not at the 2027 product-compliance deadline.
   https://digital-strategy.ec.europa.eu/en/policies/cra-reporting

2. *OpenAI opens its managed Codex harness through the Agents API*
   The public beta runs long-lived cloud agents from one API call, with hosted or self-managed compute, tools, context compaction and subagent coordination. There is no platform surcharge beyond model and tool usage.
   Why it matters: builders can test a production harness without operating the orchestration layer themselves.
   https://openai.com/index/introducing-the-agents-api/

3. *Google turns a Markdown spec into an autonomous post-training run*
   Google's new Tunix workflow lets a coding agent generate datasets and configs, launch TPU post-training, evaluate checkpoints and iterate from one specification.
   Why it matters: repeatable model adaptation is moving into the same spec-driven loop already used for coding agents.
   https://developers.googleblog.com/

4. *Salesforce ships agents that keep working across days and weeks*
   Agentforce added a long-horizon runtime with persistent memory, durable execution and steering; several service, commerce and back-office agents are GA, while its first long-running sales agent is in pilot.
   Why it matters: durable execution and approval boundaries are becoming baseline enterprise agent features.
   https://www.salesforce.com/news/stories/agentforce-job-ready-ai-agents/
