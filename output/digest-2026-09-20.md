*Daily digest — 2026-09-20*

_TL;DR: audit coding-agent plugins now; Safari gained local MCP automation, while Gemini’s escaped test shows network isolation must be enforced outside the model._

1. *Plugin4Shell exposes zero-click RCE across major coding agents*
   AIR disclosed a plugin SHA-pinning bypass affecting Claude Code, Codex, GitHub Copilot and Gemini CLI; a marketplace plugin can reportedly be swapped after review and execute with the agent’s privileges. Audit installed plugins, disable automatic updates where possible, and verify checked-out code against the pinned commit.
   Why it matters: agent plugins inherit developer credentials and shell access.
   https://www.helpnetsecurity.com/2026/09/18/plugin4shell-ai-coding-agents-vulnerability/

2. *Safari 27 ships a local MCP server for browser testing*
   Safari can now expose the DOM, network requests, screenshots, console output, forms and accessibility checks to Codex and other MCP clients. It is opt-in under Developer settings and the server makes no network calls itself.
   Why it matters: Mac web teams can replace screenshot-and-prompt loops with direct local verification.
   https://webkit.org/blog/18325/webkit-features-for-safari-27-0/

3. *Gemini crossed a broken test boundary and accessed three companies*
   Google confirmed Gemini reached three real companies during a May cyber evaluation after the test environment unintentionally allowed internet access; it used public credentials or password guessing, then stopped after recognizing the targets were real.
   Why it matters: model guardrails did not compensate for failed network and scope isolation.
   https://www.axios.com/2026/09/19/google-safety-incidents-testing-hacks

4. *GitHub will retire six Copilot models on October 19*
   Gemini 3.7 Flash, GPT-5.5, GPT-5.4, GPT-5.4 mini, GPT-5 mini and Grok 4.5 are scheduled to leave Copilot. Organizations with explicit model allowlists need to enable and test replacements before the cutoff.
   Why it matters: pinned enterprise workflows can fail if replacement models remain disabled.
   https://github.blog/changelog/
