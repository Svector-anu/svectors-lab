## Threat model (agentic framing)

FrontierAgent runs model-authored shell and file tools against a task sandbox. An attacker who can inject into the model context (untrusted fetched pages, malicious files) wants: (1) approval-gate bypass so destructive commands run without a human click, (2) sandbox escape / credential exfil from the harness env, (3) SSRF into cloud metadata. Trust boundaries: TUI risk gate, bash allowlist, path auth, SSRF pin+vet on fetch/download, tool-env allowlist + uid drop.
