## Triage

38 scanner candidates were reviewed and 0 were confirmed exploitable in the supported product.

- The AES-GCM warnings in `packages/adapters/src/secrets.ts` and `apps/web/src/screen-proxy.ts` operate on a fixed record layout: encryption emits a 16-byte authentication tag and decryption slices exactly bytes 12–28. The screen token also rejects records of 28 bytes or fewer. Supplying an altered record fails authentication; a variable attacker-selected tag length does not reach `setAuthTag`.
- The two root-container warnings describe the product's isolated computer/supervisor boundary. They are not, by themselves, an attacker-control claim or a container escape.
- The 30 mutable-action warnings are CI supply-chain hardening suggestions. The referenced actions are first-party GitHub actions or established third-party actions, and no untrusted pull-request input was found flowing into a privileged publishing step. These were not treated as product vulnerabilities.
- `deepmerge-ts@7.1.5` is transitive through Prisma configuration tooling. `image-size@1.2.1` is transitive through Metro mobile build tooling. `uuid@10.0.0` and `uuid@7.0.3` are transitive through Dockerode and Xcode build tooling. None is imported by Rakazo production source, and the vulnerable functions are not exposed to remote product input. No dependency PR was opened.

## Agentic logic audit

Deep review covered the authenticated RPC boundary and membership derivation; bot, artifact, group, routine, credential, and voice ownership checks; noVNC local HMAC and remote AES-GCM capabilities; screen-proxy header stripping; local workspace path containment and symlink resolution; sandbox execution routing; remote MCP SSRF defenses and DNS-pinned lookup; model-compatible endpoint policy; OAuth redirect equality checks; encrypted secret storage; and attachment upload/materialization limits.

The dominant pattern is fail-closed scoping: actor identity comes from the server-side session, repository queries include both workspace and user ownership, artifact reads include the owning bot/group scope, remote MCP requires HTTPS and rejects private DNS answers and redirects, and filesystem operations resolve parents/targets before enforcing root containment. The manual audit did not produce an attacker-control claim that survived call-path review.

The remaining 451 source files were inventory-reviewed by sink and boundary searches but were not individually deep-reviewed. This is a bounded audit, not a claim of exhaustive assurance.
