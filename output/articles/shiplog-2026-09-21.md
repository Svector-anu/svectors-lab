# shiplog: Skopos ships Seal and goes public

**window:** 2026-09-14T10:43:51Z → 2026-09-21T09:42:09Z

51 PRs opened this window, all 51 merged, zero left open. The headline is Skopos: a new "Seal" primitive for delegated, bounded trading policies, the unlimited-approval flow finally killed, and the repo itself flipped public. Behind it, the Aeon fork tightened its own dev loop so a change has to prove it works before it ships, and a new harness-benchmark repo landed matching the fleet's portability thesis.

## the fleet

**Skopos** (23 merged PRs) — the biggest batch. Seal is the throughline: [#114](https://github.com/Svector-anu/skopos/pull/114) made it a trading policy a second wallet can instantiate, [#115](https://github.com/Svector-anu/skopos/pull/115) wired instantiation + submit in the app, [#125](https://github.com/Svector-anu/skopos/pull/125) gave it receipts, an impact cap, and protection "as a shape," and [#120](https://github.com/Svector-anu/skopos/pull/120)/[#121](https://github.com/Svector-anu/skopos/pull/121) shipped every Seal its own share card. [#133](https://github.com/Svector-anu/skopos/pull/133) extended the signing window from 180 seconds to 20 minutes — a real usability fix, not cosmetic. Separately, [#118](https://github.com/Svector-anu/skopos/pull/118)/[#119](https://github.com/Svector-anu/skopos/pull/119) stopped asking users to sign unlimited approvals and moved the "is my approval unlimited?" check off the LLM and onto the scanner. [#116](https://github.com/Svector-anu/skopos/pull/116) added advanced orders and Seals on Circle's Arc. A run of order/quote bugs got fixed from dogfooding: a "buy $50 of NVDA" that answered with NVDA's price instead of buying it ([#123](https://github.com/Svector-anu/skopos/pull/123)), a bracket banner rendering the literal string `{token}` ([#126](https://github.com/Svector-anu/skopos/pull/126)), a successful Base order linking to Robinhood's explorer ([#128](https://github.com/Svector-anu/skopos/pull/128)), and Flash orders off Robinhood Chain that couldn't be signed at all ([#127](https://github.com/Svector-anu/skopos/pull/127)). The window closed with the repo going public: license + copyright ([#130](https://github.com/Svector-anu/skopos/pull/130)), README brought current ([#131](https://github.com/Svector-anu/skopos/pull/131)), site/docs pointed at the real repo ([#132](https://github.com/Svector-anu/skopos/pull/132)). Confirmed live: `Svector-anu/skopos` is public now.

[#93](https://github.com/Svector-anu/svectors-lab/pull/93) requires live dev-loop proof, not just a review pass, before a change counts as shipped; [#94](https://github.com/Svector-anu/svectors-lab/pull/94)/[#95](https://github.com/Svector-anu/svectors-lab/pull/95) wired that into an "offer from selected ideas" entry point; [#86](https://github.com/Svector-anu/svectors-lab/pull/86) routes Telegram replies straight into dev-loop execution. [#81](https://github.com/Svector-anu/svectors-lab/pull/81) closed an MCP-server shadow-mode isolation gap on the dispatch path. [#82](https://github.com/Svector-anu/svectors-lab/pull/82)/[#87](https://github.com/Svector-anu/svectors-lab/pull/87) bootstrapped a product feature map and made building consult it first. One reversal: [#89](https://github.com/Svector-anu/svectors-lab/pull/89) recorded an "Epoch" rebrand proposal audited against real code; [#90](https://github.com/Svector-anu/svectors-lab/pull/90) reverted it the same day.

**aeonfun/aeon** (9 merged PRs, external) — the same dev-loop live-proof requirement and Telegram routing landed upstream ([#1075](https://github.com/aeonfun/aeon/pull/1075), [#1076](https://github.com/aeonfun/aeon/pull/1076), [#1077](https://github.com/aeonfun/aeon/pull/1077), [#1070](https://github.com/aeonfun/aeon/pull/1070) adds one verified repair pass). **headless-harness-bench** (new, 2 merged PRs — one in the fork, one upstream) — "benchmark of 6 coding-agent harnesses (omp/pi/fx/opencode/dsh/crush) as headless agent loops driven by a control plane," per the repo description. Both [Svector-anu/headless-harness-bench#1](https://github.com/Svector-anu/headless-harness-bench/pull/1) and [aaronjmars/headless-harness-bench#1](https://github.com/aaronjmars/headless-harness-bench/pull/1) validated published benchmark evidence. Directly on-thesis for harness portability over harness loyalty.
