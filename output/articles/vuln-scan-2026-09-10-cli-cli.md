### Agentic logic audit (A3.6) — 0 candidates
**Threat model:** `gh` is a local CLI authenticating to github.com/GHE, rendering untrusted API content (PR/issue bodies, branch names) to a terminal, and shelling out to `git`. Top attacker goals considered: git argument/command injection via attacker-controlled branch names or URLs, terminal escape-sequence injection from untrusted API responses, and extension-install supply-chain trust.

- **Git subprocess construction** (`git/command.go`, `git/client.go`): uses `exec.Cmd` with argument arrays throughout — no shell interpolation found.
- **`gh pr checkout`** (`pkg/cmd/pr/checkout/checkout.go:150-152`) — this is exactly the entrypoint an external, untrusted PR author controls (`pr.HeadRefName` is attacker-chosen). Checked whether a branch name like `--upload-pack=...` could reach `git fetch`/`git clone` as an injected flag (a known, real vulnerability class for git-wrapping CLIs). Confirmed cli/cli already guards this: `if strings.HasPrefix(pr.HeadRefName, "-") { return fmt.Errorf(...) }`, checked before the value reaches any command queue. Not vulnerable.
- **Terminal escape-sequence injection** — cli/cli maintains its own custom CodeQL query (`.github/codeql/queries/examples/UnsanitizedResponseToTerminal{Good,Bad}.go`) with a dedicated hits/misses test suite specifically for this bug class. Already actively hunted by the maintainers' own tooling; a shallow pass here is unlikely to surface something their purpose-built query misses, and none did on manual spot-check of `pkg/iostreams`.
- **Extension install** (`pkg/cmd/extension/manager.go`) — no artifact-attestation/signature verification found on `Install`/`installBin`, despite the repo generating attestations (`generate_attestations: true`) for extensions built from their own templates. This matches the publicly documented, long-standing `gh extension install` trust model (install = trust the repo owner, same as `go install`/`npm install` from a named source) rather than a hidden logic bug — not filed as a candidate without a concrete bypass of an *advertised* guarantee.

Entrypoint coverage was bounded to N=6 per the large-repo tier (~2,500+ Go source files); the areas above were prioritized by the threat model. Remaining surface (codespaces/tunnels RPC, auth flow internals, alias expansion) was not deep-reviewed this pass.
