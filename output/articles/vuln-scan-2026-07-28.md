## Confirmed findings

### 1. HIGH — brace-expansion DoS still present on minimatch 3/5/9 lines

- **Package:** `brace-expansion@1.1.16` (via `minimatch@3.1.5`), `brace-expansion@2.1.2` (via `minimatch@5.1.9` / `minimatch@9.0.9`)
- **Advisory:** [GHSA-mh99-v99m-4gvg](https://github.com/advisories/GHSA-mh99-v99m-4gvg) / CVE-2026-14257  
- **Severity:** HIGH (CVSS 3.1 AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:H)  
- **Issue:** `expand()` bounds result *count* but not result *length*; chained brace groups OOM the Node process (uncatchable). Affected range `<= 5.0.7`; patched `5.0.8`.  
- **Repo state:** Root `package.json` already has `pnpm.overrides["brace-expansion@^5.0.0"] = "^5.0.8"` — good for the 5.x line — but **does not pin 1.x/2.x**, which remain in the vulnerable range.  
- **Suggested fix:** Extend overrides, e.g. `"brace-expansion": "5.0.8"` (or separate pins for `^1` / `^2` if a 5.x force-resolve breaks minimatch consumers), then regenerate the lockfile and run the existing test suite.  
- **Channel:** **public-pr** (dependency CVE already public) — **blocked this run**: `gh repo fork` / forks API returned 403 for `github-actions[bot]`; no `GH_GLOBAL` PAT. Operator can open the bump PR from the note above.

### 2. MODERATE — `@anthropic-ai/sdk@0.81.0` still pulled by claude-agent-sdk

- **Package:** `@anthropic-ai/sdk@0.81.0` via `@anthropic-ai/claude-agent-sdk@0.2.112` (`packages/maker-core`, `packages/maker-cc-manager`)  
- **Advisory:** [GHSA-p7fg-763f-g4gf](https://github.com/advisories/GHSA-p7fg-763f-g4gf) / CVE-2026-41686  
- **Severity:** MODERATE — insecure default file permissions on the SDK’s local filesystem Memory tool  
- **Repo state:** `packages/maker-core` already depends on `@anthropic-ai/sdk@^0.91.1` directly (patched line), but the agent SDK still resolves **0.81.0** beside it.  
- **Suggested fix:** pnpm override `"@anthropic-ai/sdk": "0.91.1"` (or newer) and/or bump `@anthropic-ai/claude-agent-sdk` when a release pulls the fixed SDK; verify Memory-tool paths on remote SSH hosts (`maker-cc-manager`).  
- **Channel:** **public-pr** — same fork 403 block as above.
