# Vuln scan — 2026-08-18

Run manually (not via GitHub Actions — the automated `vuln-scanner` dispatch is
currently broken repo-wide; see note at the end). Three targets, following
Arm A end to end: scan → mandatory prior-art check → triage → fix/route →

## 2. yetone/cumora

No SECURITY.md issue here — PVR is enabled in principle but not needed this
run since every finding was a dependency CVE (public-PR path, doesn't need a
disclosure channel). No open PRs at all on the repo (zero prior art, no
Dependabot noise to dedup against).

osv-scanner found **148 vulnerability entries** across 5 manifests
(root, `agent-fuse/go.mod`, `benchmarks/`, two Cloudflare workers). trufflehog

| Package | Before | After | Advisories |

| dompurify | 3.4.3 | 3.4.13 | 10 (production dep — sanitizes untrusted HTML) |

**PR opened:** [yetone/cumora#8](https://github.com/yetone/cumora/pull/8)

PR; called out in the PR body for the maintainer to schedule and test
properly rather than auto-bumped blind. A long tail of lower-severity /
dev-tooling-only findings (esbuild, tar, ws, undici, shell-quote, protobufjs,

## 3. DannyMac180/sol-advisor

Picked as the dependency-scan-only target (no SECURITY.md, PVR disabled).
Turned out to have no dependency manifests at all — it's a small Codex/agent
plugin package (TOML agent configs + 3 shell scripts), not a conventional
app. osv-scanner found nothing to scan; trufflehog clean.

Manually reviewed all three shipped shell scripts (`install-agents.sh`,
`inspect-agent-runtime.sh`, `verify.sh`) for the usual footguns — TOCTOU,
symlink races, glob/argument injection, `eval`/`curl|sh` patterns. Found
none. The install script is unusually well-hardened: atomic `ln`-based
install (fails rather than silently overwriting a changed destination),
explicit symlink/non-regular-file rejection, pre- and post-install digest
verification. The session-inspector script validates its `THREAD_ID`
argument against a strict UUID regex before ever using it in `find -name`,
and scopes its temp-file cleanup to a fixed prefix.

**Result: clean.** No PR, no PVR, nothing to route.
