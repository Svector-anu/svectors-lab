## Threat model and agentic review

OpenHuman is a local-first personal AI and agent-runtime application with desktop/mobile hosts, messaging integrations, filesystem and shell tools, and optional network-facing services. The highest-value attacker goals are invoking privileged IPC or agent tools, escaping filesystem/shell policy, and exfiltrating credentials or personal memory through SSRF or unauthenticated network surfaces. Trust boundaries include remote channel/webhook input to the agent, browser/webview content to Tauri IPC, local/LAN clients to RPC and hosted-directory listeners, and model-generated arguments to privileged tools.

Deep-reviewed top exposure classes:

1. Core RPC public binding and bearer-token provisioning (`security/pairing.rs`) — non-loopback binds generate or require a 256-bit token and persist it owner-only.
2. Tauri/webview IPC and mobile host dependency boundary — found the confirmed dependency issue below.
3. Agent shell execution (`tools/impl/system/shell.rs`) — environment is cleared to an explicit functional allowlist; runtime policy and approval gates mediate execution.
4. Outbound HTTP/SSRF guard (`tools/impl/network/url_guard.rs`) — rejects local/private/reserved targets and validates resolved DNS addresses; no confirmed bypass in the reviewed path.
5. Ad-hoc hosted-directory HTTP server (`http_host/ops.rs`) — defaults to generated basic authentication and canonicalizes the served root; disabling auth is explicit operator configuration.
6. OAuth callback handling (`app/src-tauri/src/loopback_oauth.rs`) — loopback-only listener with state matching and bounded request handling.

The remaining production entrypoints across channels, integrations, wallet/payment, memory, workflow, MCP, voice, and desktop modules were inventoried but not deep-reviewed because the repository exceeded the six-entrypoint budget.

Agentic candidates: 0 confirmed code candidates.

## Confirmed finding

### High — Tauri origin confusion in mobile host

- Advisory: [GHSA-7gmj-67g7-phm9](https://github.com/advisories/GHSA-7gmj-67g7-phm9) / CVE-2026-5947
- Affected direct dependency: `tauri = "=2.10.3"` in the mobile host
- Fixed version: `2.11.1`
- Impact class: a remote page can be misclassified as local and invoke local-only IPC commands under affected configurations
- Channel: public dependency-fix PR, because the advisory is already disclosed
- Fix: [tinyhumansai/openhuman#5814](https://github.com/tinyhumansai/openhuman/pull/5814)

The manifest and mobile Cargo lockfile were updated. Dependency resolution and `git diff --check` passed. A full Linux `cargo check` progressed into native compilation but could not finish because the runner lacks `glib-2.0` and `gobject-2.0` development packages; the PR states this limitation.
