## Candidates reviewed

**1. `paste 1.0.15` → RUSTSEC-2024-0436 (osv hit) — discarded, non-actionable.**
This is the "`paste` is unmaintained" advisory, not a fixable vulnerability: the crate is archived, **no patched version exists to bump to**, and it is a build-time transitive proc-macro dependency (no runtime attack surface). The skill's public-PR channel is for *already-disclosed CVEs with a fix to bump to* — there is nothing to bump here, so no PR is warranted. Noted, not filed.

**2. Malformed-input parsing — the stated attack surface — reviewed by hand, discarded.**
The SECURITY.md points squarely at crafted `.tv`/`.tvim` bytes, so the load path got the deepest read:
- `io_v7.rs` `load_image` / `parse_header_at` / `parse_header_slot`: every header field is read through a bounds-checked `.get()`; the untrusted row count `n` is validated against the real file length *before* it sizes anything; `n_units`/`n_mat` are capped at `MAX_OPS`; each pending-op block index is checked `< n/BLOCK` and each lane `< BLOCK` **before** it indexes `scales[slot]`/`ids[slot]`; offset arithmetic uses `checked_mul`/`checked_add`; superblock and per-commit delta are CRC-verified.
- `convert.rs` `read_legacy` (the v5/v6 back-compat reader — the less-trodden path): `n_vectors` is bounded by `n_vectors.saturating_mul(5) > bytes.len()` **before** any size arithmetic runs; all reads go through checked `.get()` / `rd_*` helpers with `checked_add`.
- `pack.rs` decoders operate only on buffers sized from already-validated geometry; the raw-caller footguns are gated behind `from_parts`, which validates first.

**3. FFI `unsafe` (`turbovec-python/src/par_copy.rs`) — discarded.**
`par_copy_into` reserves `slice.len()`, restricts the spare-capacity slice to `slice.len()`, writes every element via the parallel copy, and only then calls `set_len(slice.len())`. The `unsafe` is sound.

**4. Search-time `unsafe` SIMD kernels (`search.rs`, 52 `unsafe` sites) — discarded.**
Query length is validated against the index dimension at the public entry (`lib.rs:1364`, `queries.len() != nq * dim`) before any kernel runs; prefetch reads are guarded (`pf + 64 <= blocked_codes.len()`). Kernels consume LUTs/blocked codes derived from validated geometry.

**Secrets:** 17 files matched secret *keywords*, but every hit is either GitHub Actions `secrets.*` references in workflows or environment-variable-based tokens in the integration tests — 0 hardcoded credential literals. A verified-secret scanner would report 0.

## Why clean, not thin

turbovec is an unusually well-hardened target: it ships a dedicated adversarial test suite (`tests/adversarial_durability*.rs`, `input_validation*.rs`, `avx512_tail_simulation.rs`) and the parsers visibly reflect that — untrusted lengths are bounded before use, every field read is fallible, and the crash-consistency format is CRC-gated. The malformed-input bug class its own SECURITY.md worries about is the one it defends hardest against.
