Attacker goals: steal OAuth refresh/access tokens, switch/hijack local account sessions, abuse embedded OAuth client credentials, or reach LAN-exposed helpers. ## Confirmed findings

### 1. Critical — hardcoded Google OAuth client secret (CWE-798)

- **Channel:** private email (PVR off) — staged `memory/pending-disclosures/jlcodes99-cockpit-tools-2026-09-02.md` (`auto_send: true`)
- **PoC gate:** not-required (credential verified live against Google token endpoint: `invalid_grant`)
- **Public detail:** location summarized as `oauth.rs` under src-tauri and cockpit-core; secret value redacted from this report and from the staged email body
- **Impact:** compromised Google Cloud OAuth app client usable by anyone with the repo; scopes include `cloud-platform`

### 2. Medium — embedded VS Code GitHub OAuth client credentials

- **Channel:** bundled in the same private email
- **Evidence:** TruffleHog `--only-verified` GitHubOauth2 on `github_copilot_oauth.rs` (filesystem + git history)
- **Note:** client id matches the well-known VS Code GitHub OAuth app; still should not ship third-party client secrets — register a first-party app

### 3. Medium — WebSocket account switch/list without session auth

- **Channel:** bundled in the same private email (not a public PR)
- **Detail:** after #1104, token export/add/delete require `auth_token`, but `SwitchAccount` / `GetAccounts` / `GetCurrentAccount` do not; no Origin check on `accept_async`; bind is `0.0.0.0` while README claims `127.0.0.1` (loopback allowlist still applies)
- **PoC gate:** not required at Medium; DNS-rebinding elevation noted for maintainers

### 4. Low — default web-report token

- **Channel:** bundled in private email
- **Detail:** `default_report_token` is `change-this-token`; report server binds `0.0.0.0` when enabled (default off)

### Dependency CVEs (already public) — public PR

- **Channel:** public PR https://github.com/jlcodes99/cockpit-tools/pull/2217
- **Packages:** openssl → 0.10.81; rustls-webpki → 0.103.15; transitive aws-lc-sys → 0.45.0; quinn-proto → 0.11.17
- **Prior-art:** no open duplicate PR/issue found
- npm HIGH (vite/postcss/nanoid/…) were `dep_groups=dev` only — not included in the runtime bump PR
